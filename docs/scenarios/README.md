# Σενάρια δοκιμής (ιδιοκτήτης 17/10)

Δέκα διαφορετικά κτίρια, το καθένα: **(1) σχεδιασμός και ευκολία**, μετά **(2) στατικά** στο ίδιο κτίριο, μετά
**(3) Η/Μ, ντουλάπια, έπιπλα**. Ελέγχουμε από δύο μεριές: ο agent τα χτίζει με τις ίδιες ενέργειες του UI και γράφει
αναφορά· ο ιδιοκτήτης ανοίγει το `.archforge` και τα ελέγχει κομμάτι κομμάτι.

**Κανόνες (ιδιοκτήτης 17/10):** κάθε σενάριο πολύπλοκο και με διαφορετικά στοιχεία από τα άλλα· μέσα Η/Μ, κουζίνες,
μπάνια, έπιπλα· το σύνολο βγαίνει σε προσφορά· όλη η λίστα ελέγχων τρέχει σε κάθε σενάριο και τα ευρήματα
διορθώνονται πριν το επόμενο.

**Πύλη ποιότητας** (`QUALITY_GATE.md`, `archforge/scenarios/gate.py`): κάθε σενάριο βγάζει `Sxx_<όνομα>.archforge`,
`Sxx_REPORT.md` (PASS / FAIL / N/A, ιστορικό ευρημάτων FIXED / OPEN με αρχεία και commit) και στιγμιότυπα: κάτοψη ανά
περιβάλλον (Αρχιτεκτονικό / Φέρων / Η/Μ) και 3D (εξωτερικά, από πάνω, κουκλόσπιτο, Φέρων, Η/Μ) — το 3D με την ίδια
σελίδα της εφαρμογής σε headless Chromium.

Ξαναχτίσιμο: `py scripts/build_scenarios.py` (ή `py scripts/build_scenarios.py 01`). Κάθε σενάριο είναι και test
(`tests/test_scenarios.py`). Η γεωμετρία των σεναρίων είναι σχέδιο δοκιμής, όχι πραγματικό έργο.
