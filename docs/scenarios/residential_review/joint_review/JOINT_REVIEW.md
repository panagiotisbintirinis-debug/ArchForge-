# Επανέλεγχος ενώσεων τοίχου–πλάκας

Δύο διαφορετικά ευρήματα: το αρχικό πραγματικό διάκενο από τις ασύμβατες στάθμες/περιγράμματα των παλιών αρχείων και, μετά τη γεωμετρική διόρθωση, η γκρι ακμή της πλάκας επειδή ο renderer αγνοούσε το υλικό της επιφάνειας `edge`.

Η γεωμετρία παραμένει ανεξάρτητη από το χρώμα. Οι νέοι έλεγχοι ελέγχουν πραγματικά τρίγωνα στη νότια πρόσοψη των S02–S10, σε τέσσερις οριζόντιες θέσεις και 61 υψόμετρα ανά ένωση ορόφου. Αρνητικό παράδειγμα επαναφέρει κενό στο S10: ο έλεγχος το εντοπίζει ακόμη και με τελείωμα λευκού σοβά. Δεν αποδεικνύεται με αυτά ότι ελέγχθηκε κάθε σημείο ολόκληρου κτιρίου.

Το PR #134 διορθώνει την απόδοση υλικού ανά επιφάνεια πλάκας χωρίς αλλαγή τριγώνων/κορυφών ή του επάνω δαπέδου. Στα δικά μας σχέδια οι ακμές και οι εξωτερικοί τοίχοι έχουν κοινή επιλογή υπάρχοντος λευκού σοβά. Δεν προστέθηκε αυθαίρετο πάχος/στρώση ή κανονιστικός ισχυρισμός.

`S10_before_finish`: πραγματική παλιότερη λήψη μετά την πρώτη γεωμετρική διόρθωση, με γκρι ακμή. `S10_front`: πραγματική νέα λήψη με αποδιδόμενο τελείωμα. Τα νέα `.archforge` χρειάζονται και το νέο πρόγραμμα· παλιά έκδοση εξακολουθεί να αγνοεί την ανάθεση υλικού ακμής.

Τοπική πλήρης εκτέλεση: 1.841 καταγεγραμμένα test cases πέρασαν. Ένα προαιρετικό module LangGraph δεν συλλέχθηκε επειδή λείπει το προαιρετικό dependency (pytest importorskip). Τα αρχεία δοκιμών εκτελέστηκαν σε ξεχωριστές διεργασίες για την αποδέσμευση Qt/OCP. Η ατομική διεργασία του μη συλλεγμένου module επέστρεψε code 5· δεν παρουσιάζεται ως εκτελεσμένο ή περασμένο τεστ. Πρόσθετος τελικός έλεγχος 64 στοχευμένων περιπτώσεων πέρασε, συμπεριλαμβανομένου του S03. Η ανεξάρτητη CI καταγράφεται στο PR #134.
