# S02 — δικό μας σχέδιο για έλεγχο

Αρχείο: `tests/residential_scenarios/S02_split_level_hillside_house.archforge`.
Δεν προέρχεται από τα σχέδια του Claude και δεν αλλάζει τον φάκελο `docs/scenarios/S02_syntheto.archforge`.

Το αρχείο περιέχει πραγματικές οντότητες επίπλων βιβλιοθήκης. Αν λείπουν στη δική σας εγκατάσταση, κατεβάστε μαζί τον φάκελο `library_assets` και το `install_s02_assets.py`, και εκτελέστε `python install_s02_assets.py` πριν ανοίξετε το σχέδιο. Το πρόγραμμα εγκατάστασης διατηρεί υπάρχοντα assets και δεν αλλάζει σχέδια.

Τα αρχεία `S02_SHARED_GATE.md` και `S02_GATE_CHECKS.json` διατηρούν τα ανοιχτά FAIL. Δεν πρόκειται για ολοκληρωμένη ή πιστοποιημένη μελέτη. Κρυφός φωτισμός: υπάρχουν εσοχές και ταινίες ως επεξεργάσιμες οντότητες, αλλά τα στοιχεία ισχύος/φωτεινότητας προϊόντος παραμένουν άγνωστα.
