# ArchForge — αποτύπωση δυνατοτήτων (Νοέμβριος 2026)

Για προώθηση και για κρίση. Κάθε γραμμή ελέγχθηκε στον κώδικα (branch `ccr-c3212ac2-dx34ld`, commit `6de2039`), όχι
από μνήμης. Μέτρο σύγκρισης: η λίστα «βασικές (CAD) / ειδικές (BIM) ικανότητες» ενός επαγγελματικού προγράμματος
(Revit, Archicad, Vectorworks, AutoCAD Architecture).

**Κατάσταση:** πρόγραμμα υπό ανάπτυξη, όχι εμπορική έκδοση. ~100.000 γραμμές Python (PySide6 / Qt, 3D σε WebGL),
333 αρχεία τεστ, **2468 αυτόματα τεστ περνούν** (06/11/2026). Η δοκιμή στα Windows από τον ιδιοκτήτη εκκρεμεί.

Σύμβολα: ✅ υπάρχει και δουλεύει (με τεστ) · 🟡 μερικώς · ❌ δεν υπάρχει.

## 2. Ειδικές ικανότητες (BIM)

| Ικανότητα | ArchForge | Τι ακριβώς |
|---|---|---|
| Παραμετρικά στοιχεία | ✅ | Τοίχοι με σύνθεση στρώσεων, πόρτες / παράθυρα φιλοξενούμενα στον τοίχο, πλάκες, χώροι, οροφές, στέγες, σκάλες, ράμπες, κολόνες, δοκοί, θεμελίωση, κάγκελα, πισίνα, έδαφος. Ο τύπος κουφώματος (ανοιγόμενο, συρόμενο, ρολό …) παράγει 3D και σύμβολο κάτοψης. |
| Αμφίδρομη συσχέτιση | ✅ | **Ένα** μοντέλο (`Document`): κάτοψη, 3D, τομές, όψεις, λίστες, θερμική εικόνα διαβάζουν το ίδιο. Κάθε αλλαγή από οποιοδήποτε σημείο (κάτοψη, 3D, Ιδιότητες, λίστα) περνά από την ίδια στοίβα εντολών με αναίρεση / επανάληψη. |
| Πληροφορία στα αντικείμενα | ✅ | Υλικά με λ (ΤΟΤΕΕ 20701-2 Πίν. 2) και **πηγή / κατάσταση ανά τιμή**, U τοίχων, θερμικά στοιχεία κουφωμάτων (Uf, Ug, Ψg, πλαίσιο, g, κατασκευαστής), τιμές, φάση (νέο / υφιστάμενο / καθαίρεση). Πυραντίσταση: ❌. |
| Πίνακες και επιμετρήσεις | ✅ | **Ζωντανές λίστες**: κουφώματα (τυπολογία, υάλωση, ρολό, σίτα, Uw και πηγή του, απαίτηση), κέλυφος με έλεγχο Umax, χώροι, κυκλώματα. Επιμέτρηση εργασιών, τιμολόγιο, προσφορά πελάτη, υλικά ανά επάγγελμα. Εξαγωγή PDF και Excel. |
| Ανίχνευση συγκρούσεων (clash) | ❌ | Δεν υπάρχει γενικός έλεγχος σύγκρουσης αρχιτεκτονικού / στατικού / Η/Μ. Υπάρχουν μόνο τοπικοί έλεγχοι (η σκάλα με τα γύρω της, τα ανοίγματα μέσα στον τοίχο τους). |
| Διαλειτουργικότητα | 🟡 | **Εξαγωγή IFC4** (όροφοι, όλα τα δομικά στοιχεία), **εισαγωγή IFC** (όροφοι, τοίχοι, κουφώματα, με μία αναίρεση), **εξαγωγή DXF** ανά όροφο, **PDF** σχεδίων σε κλίμακα. Εισαγωγή σχεδίων PDF ως υπόβαθρο και αναγνώριση τοίχων / κτιρίου από αυτό. Εισαγωγή DXF / DWG: ❌. |
| Φωτορεαλισμός, VR | 🟡 | PBR σε πραγματικό χρόνο, ήλιος ανά ημερομηνία, φωτιστικά με θερμοκρασία χρώματος και σκιές, φωτογραφία. Video, path tracing, VR: ❌. |
| Ενεργειακή ανάλυση | ✅ / 🟡 | **Δυνατό σημείο:** θερμοκρασίες σχεδιασμού (ΤΟΤΕΕ 20701-3), U από στρώσεις, θερμογέφυρες (Πίν. 15), Umax (ΤΟΤΕΕ 20701-2/2021 Πίν. 5α νέο / 5β ανακαίνιση), **θερμική εικόνα όψης με 3Δ αγωγή** (σαν θερμοκάμερα, σήμερα / πρόταση), ενδεικτική ισχύς θέρμανσης, **solver σχεδιασμού κουφώματος** (Πίν. 9–12). Μελέτη ηλιασμού / σκίασης, ηλιακά κέρδη, πλήρης ΜΕΑ ΚΕΝΑΚ: ❌. |

## 3. Πέρα από τη λίστα (ό,τι δεν έχουν συνήθως τα αρχιτεκτονικά προγράμματα μαζί)

- **Στατικά:** επίλυση πλαισίου 3D (μέθοδος δυσκαμψίας), ιδιομορφές, σεισμός (EN 1998-1 με Ελληνικό Προσάρτημα),
  σχεδιασμός οπλισμένου σκυροδέματος (EN 1992-1-1) και χάλυβα, θεμελίωση, ξύλινες στέγες και πατώματα.
- **Η/Μ:** ηλεκτρολογικά (κυκλώματα, πίνακας, σωληνώσεις, ασθενή, KNX), ύδρευση / αποχέτευση, θέρμανση, αερισμός,
  φωτισμός ανά χώρο, επιμετρήσεις και κοστολόγηση ανά επάγγελμα.
- **Περιβάλλων χώρος:** έδαφος με τοπογραφία και προφίλ, πλατώματα, τοίχοι αντιστήριξης, μονοπάτια, φυτά, πισίνα.
- **Οργανική / μηχανολογική μοντελοποίηση:** Bio-Spectre pods, sculpt, μηχανισμοί.
- **Βοηθός AI προαιρετικός:** το πρόγραμμα δουλεύει χωρίς AI. Όταν καλείται, ο βοηθός περνά από τις ίδιες εντολές με το χέρι.
- **Αρχή «καμία μαντεμένη τιμή»:** κάθε αριθμός έχει πηγή και κατάσταση. Ό,τι δεν είναι γνωστό λέγεται «δεν υπολογίστηκε».

## 4. Για την κρίση: τι λείπει ή είναι αδύναμο

1. **Ελεύθερη 2D σχεδίαση:** μπήκε 06/11 (γραμμή, πολυγραμμή, ορθογώνιο, πολύγωνο, κύκλος, τόξο, κείμενο, γέμισμα).
   Λείπουν ακόμη οι εντολές επεξεργασίας του CAD: offset, trim / extend, fillet, καθρέφτης, blocks χρήστη.
2. **Clash detection** μεταξύ αρχιτεκτονικού, στατικού και Η/Μ.
3. **Εισαγωγή DWG / DXF** (υπάρχει μόνο εξαγωγή) και πληρέστερη εισαγωγή IFC (σήμερα μόνο τοίχοι και κουφώματα).
4. **Φύλλα σχεδίων (layout / sheets)** με πινακίδα και πολλές προβολές σε ένα φύλλο, όπως Revit / Archicad. Σήμερα το
   PDF δίνει κατόψεις σε κλίμακα, επιμέτρηση και προσφορά.
5. **Ηλιασμός / σκίαση / ηλιακά κέρδη** και πλήρης ΜΕΑ ΚΕΝΑΚ.
6. **Συνεργασία πολλών χρηστών** (κοινό μοντέλο, δικαιώματα): λείπει.
7. **Ωριμότητα:** δεν έχει δοκιμαστεί ακόμη από πραγματικούς χρήστες σε μεγάλα έργα. Η «κριτική από επτά ρόλους»
   (04/11) έγινε από το ίδιο μοντέλο AI με διαφορετικούς ρόλους, όχι από ανθρώπους. Το README γράφει ακόμη «53 τεστ»
   (παλιό): χρειάζεται ενημέρωση πριν από δημόσια παρουσίαση.
