## 4. Μενού αντικειμένου: Τοίχος (ανεπτυγμένο)

Επιλέγεις τοίχο → μικρό μενού δίπλα του → ενότητες. ✓ υπάρχει σήμερα (σε ποιο σημείο) · ✗ λείπει.

**Γεωμετρία**
- ✓ Μήκος, ύψος, πάχος, x/y άκρων — Ιδιότητες (αριθμοί)
- ✓ Γραμμή αναφοράς: άξονας / παρειά — μόνο στη σχεδίαση (Σχεδίαση τοίχου από)
- ✓ Τοιχία: ύψος από το έδαφος
- ✓ Καμπύλος: ακτίνα, τμήματα
- ✗ Γραμμή αναφοράς ενός υπάρχοντος τοίχου
- ✗ Σύνδεση με όροφο (κορυφή ως την πλάκα του επάνω ορόφου)

**Σύνθεση**
- ✓ Τύπος τοίχου (στρώσεις, U) — Ιδιότητες
- ✓ Υλικό / Υλικά ανά όψη — δεξί κλικ ▸ Υλικά, Πινέλο
- ✓ Φέρων / μη φέρων
- ✗ Εσωτερική / εξωτερική πλευρά (αναστροφή στρώσεων)

**Ανοίγματα**
- ✓ Πόρτα, Παράθυρο, Άνοιγμα, Τοξωτό — Κατασκευή ▸ Κουφώματα (κλικ στον τοίχο)
- ✗ Λίστα των κουφωμάτων ΑΥΤΟΥ του τοίχου με μετάβαση σε καθένα

**Συνδέσεις**
- ✓ Γωνία με άλλο τοίχο, Διαχωρισμός εδώ, Μετακίνηση κατά… — δεξί κλικ ▸ Επεξεργασία τοίχου
- ✗ Γειτονικοί τοίχοι (λίστα)
- ✗ Πλάκα επάνω / κάτω
- ✗ Στέγη επάνω
- ✗ Εκκρεμότητες σύνδεσης (π.χ. τοίχος που δεν κλείνει)
- ✗ Απομόνωση: μόνο αυτός και ό,τι τον αγγίζει

**Εμφάνιση στα σχέδια**
- ✓ Layer / Περιβάλλον (Αρχιτεκτονικό·Φέρων·Η/Μ)
- ✗ Γραμμές, διαγράμμιση ανά στρώση στην κάτοψη και στην τομή

- Αντικείμενο: Τοίχος / Γεωμετρία: Τοιχία: ύψος από το έδαφος (επιλεγμένοι τοίχοι)
- Αντικείμενο: Τοίχος / Συνδέσεις: Γωνία (2 τοίχοι) · Γωνία επιλεγμένου τοίχου…
- Αντικείμενο: Χώρος / Γεωμετρία: Διαστάσεις δωματίου… (κλικ μέσα του)
- Αντικείμενο: κοινά (Μετακίνηση·Περιστροφή·Τέντωμα·Διπλασιασμός·Διαγραφή): Μετακίνηση · Περιστροφή · Τέντωμα · Διπλασιασμός · Διαγραφή
