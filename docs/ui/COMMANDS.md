304 εντολές · 304 με εικονίδιο · 304 με εξήγηση. Βγαίνει από το πρόγραμμα: `python scripts/toolbox/tool_map.py --commands docs/ui/COMMANDS.md` (η εξήγηση = η κάρτα του ποντικιού).


## Έργο


### Αρχείο

| Εντολή | Τι κάνει | Συντόμευση |
|---|---|---|
| Νέο έργο | Ξεκινά άδειο έργο. Αν το τρέχον έχει αλλαγές, ρωτά πρώτα αν θα αποθηκευτούν. | Ctrl+N |
| Άνοιγμα έργου… | Ανοίγει αρχείο .archforge από τον υπολογιστή. | Ctrl+O |
| Άνοιγμα δείγματος… | Ανοίγει ένα από τα έτοιμα δείγματα κατοικιών (S01–S10) για δοκιμή. |  |
| Αποθήκευση | Αποθηκεύει το έργο (ποτέ μισό αρχείο: το παλιό μένει μέχρι να γραφτεί το νέο). | Ctrl+S |
| Ανάκτηση μη αποθηκευμένης εργασίας… | Επαναφέρει δουλειά από την αυτόματη αποθήκευση μετά από απρόβλεπτο κλείσιμο. |  |
| Αρχική σελίδα | Ανοίγει την αρχική σελίδα με τα πρόσφατα έργα και τα δείγματα. |  |
