Rendering model (DESIGN_DEFAULT, already used by ArchForge):
Point intensity = luminous flux / (4*pi).
Spot intensity = luminous flux / (2*pi*(1-cos(full_beam/2))).
These uniform distributions approximate light appearance; they do not reproduce a manufacturer's measured candela diagram.
Ring/line: reference flux is divided between 8 / 3 emitters respectively, without multiplying the total.
Kelvin-to-RGB uses the same approximate display conversion as ArchForge.
The reference sources listed above are non-dimmable products. The package's brightness control is a rendering control.
